# 🧠 PROMPTUS — ИИ-ментор по промпт-инжинирингу

**PROMPTUS** — это учебный ИИ-агент, созданный для помощи студентам в изучении курса по промпт-инжинирингу. Он отвечает на вопросы по лекциям, переформулирует сложные концепции и помогает проверять знания через тестирование.

---

## 🚀 Демо

Приложение доступно по ссылке:  
👉 **[https://ai-mentor-course.streamlit.app/](https://ai-mentor-course.streamlit.app/)**

---

## ✨ Возможности

- **🧠 Синтез с ИИ** — задавай вопросы по курсу, PROMPTUS найдёт ответ в лекциях и переформулирует его с помощью GigaChat.
- **📝 Тестирование** — проверь свои знания: PROMPTUS задаёт случайный вопрос по лекциям и оценивает твой ответ.
- **🛠 Отладка** — просмотр базы знаний, случайный фрагмент, статистика, список лекций.
- **ℹ️ О PROMPTUS** — информация о проекте, схема работы и история создания.

## 📚 Материалы

База знаний PROMPTUS состоит из **158 фрагментов**, извлечённых из **28 PDF-лекций** по промпт-инжинирингу.

В курсе рассматриваются темы:
- Введение в промпт-инжиниринг
- Простые и продвинутые типы промптов
- Инструменты для создания промптов
- Генерация изображений и видео
- Оптимизация и безопасность промптов

## 🚀 Как запустить локально

### 1. Клонируй репозиторий

```bash
git clone https://github.com/Dmirii/ai-mentor-course.git
cd ai-mentor-course
2. Установи зависимости
bash
pip install -r requirements.txt
3. Создай базу знаний
bash
python make_db.py
4. Запусти приложение
bash
streamlit run app.py
Приложение откроется в браузере по адресу http://localhost:8501.
