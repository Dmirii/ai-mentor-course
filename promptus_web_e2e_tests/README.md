# PROMPTUS — внешний автотест опубликованного веб-приложения

Эта папка содержит отдельный Python-скрипт, который запускается на ноутбуке и тестирует сайт:

```text
https://ai-mentor-course.streamlit.app/
```

Он не запускает локальный Streamlit, не требует копии вашего основного проекта и не содержит API-ключ.

## Файлы

```text
promptus_web_e2e_tests/
├── check_environment.py          # сначала запустить эту проверку
├── web_e2e_tests.py              # сам браузерный автотест
├── web_test_cases.json           # 12 тестовых вопросов
├── requirements-web-e2e.txt      # Playwright, если его ещё нет
└── README.md                     # эта инструкция
```

## Шаг 1. Сначала ничего не устанавливайте

Скачайте **все пять файлов** в одну папку на ноутбуке. Затем откройте терминал именно в этой папке и выполните:

```bash
python check_environment.py
```

На Windows вместо `python` иногда нужна команда:

```bash
py check_environment.py
```

Проверка ничего не устанавливает. Она покажет:

- есть ли Python 3.10+;
- находится ли Playwright;
- скачан ли Chromium для Playwright;
- доступны ли файлы;
- отвечает ли опубликованный сайт.

Если все пункты покажут `[OK]`, устанавливать ничего не нужно.

## Шаг 2. Если Playwright или Chromium отсутствуют

Только если проверка напишет, что Playwright/Chromium не найден, выполните:

```bash
python -m pip install -r requirements-web-e2e.txt
python -m playwright install chromium
```

В Windows при необходимости замените `python` на `py`.

## Шаг 3. Первый тест

Запустите один сценарий с видимым окном браузера:

```bash
python web_e2e_tests.py --only W01 --headed
```

Браузер сам откроет опубликованный PROMPTUS, задаст вопрос и сделает скриншот.

## Шаг 4. Все 12 тестов

Когда W01 прошёл, выполните:

```bash
python web_e2e_tests.py --headed
```

Позже можно запускать без видимого окна браузера:

```bash
python web_e2e_tests.py
```

## Результаты

После выполнения появится папка:

```text
artifacts/web_e2e/
├── promptus_web_e2e_....csv
├── promptus_web_e2e_....json
├── promptus_web_e2e_....md
└── screenshots/
```

Для итоговой работы нужен прежде всего CSV. В нём будут реальные ответы веб-приложения, время ответа, автооценка и поля `final_score`, `final_comment` для итоговой ручной оценки.

## Если проверка URL показывает редирект на Streamlit login

Откройте сайт вручную в режиме инкогнито. Внешнее браузерное тестирование возможно только если чат доступен без обязательного входа в Streamlit. Если вход обязателен, сначала нужно исправить настройки доступа приложения.
